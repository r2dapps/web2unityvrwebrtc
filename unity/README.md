# Unity WebRTC Scripts

This folder contains the Unity C# scripts (`UnityVRWebRTC.cs`, `AetherCareUIController.cs`) and UI Toolkit assets required to run the Unity side of the AetherCare WebRTC Console.

1. Drop this folder into your Unity project's `Assets/` directory.
2. Ensure you have the `com.unity.webrtc` (version 3.x) package installed.
3. Attach `UnityVRWebRTC` and `AetherCareUIController` to a GameObject, assign the UI document, and configure your settings in the Inspector.
